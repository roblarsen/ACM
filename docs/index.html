The Assumptions & Constraints Manifest (ACM) is a machine-readable, human-auditable contract format that stops AI-generated code from smuggling silent operational debt into production.

The Happy Path Trap

Generative AI made Day-1 syntax nearly free, creating an asymmetric Day-2 maintenance crisis. LLMs write clean code that passes unit tests while hiding lethal runtime assumptions.

Silent Architectural Drift

Agents assume process-local in-memory caches run on single instances, omit timeout budgets, and write non-atomic dual-writes without transactional outboxes.

Review Paralysis

Senior engineers spend 80% of PR review energy reverse-engineering what the LLM assumed about concurrency, retries, and failure modes instead of reviewing intent.

Superficial Green Tests

Happy-path test suites pass effortlessly against implicit assumptions—until production traffic spikes, a pod restarts, or a downstream API stalls.

Typed Semantic Contracts & Distributed Primitives

ACM replaces vague checklists with typed contract statuses, mandatory proof obligations, first-class distributed primitives, and CI-enforced risk floors.

guaranteed + evidence conditional + conditions unsupported + failure_mode unknown not_applicable
PULL_REQUEST_TEMPLATE.md / .acm.md YAML Frontmatter + Auditable Taxonomy 
<!-- ACM-START -->
---
acm_version: "1.1"
change_type: "feature"
risk_level: "critical"
contracts:
  idempotency:
    status: "unsupported"
    failure_mode: "Retrying POST re-authorizes payment and duplicates inventory holds."
  concurrency_safety:
    status: "unsupported"
    failure_mode: "checkStock() and holdStock() interleave under concurrent requests."
  horizontal_scalability:
    status: "guaranteed"
    evidence: "src/checkout.ts:14-48 — stateless handler; state lives in Postgres & Stripe."
  strict_ordering:
    status: "not_applicable"
  data_loss_safety:
    status: "unsupported"
    failure_mode: "Dual-write vulnerability: Stripe charge succeeds before DB commit without Outbox."
distributed_primitives:
  consistency_model: "eventual"
  delivery_semantics: "at_least_once"
  degradation_mode: "fail_closed"
  backpressure_strategy: "fail_fast"
---

### 1. Invariants & Data Model Boundaries
* **Payload Validation:** Assumes non-empty items array; amountCents > 50.

### 2. State & Runtime Topology
* **Concurrency & Locking:** No distributed Redlock or row-level locks across inventory loop.

### 3. Environmental & Network Assumptions
* **Cross-Boundary Atomicity:** Missing Saga rollback if item #2 fails after item #1 is held.

### 4. Explicit Non-Goals & Unhandled Failure Modes
* **Degradation:** Stripe timeouts bubble as unhandled HTTP 500 without releasing stock holds.
<!-- ACM-END -->

Where ACM Fits

ACM complements existing engineering formalisms by closing the operational gap at the Pull Request change horizon.

Formalism Scope & Granularity Lifecycle Phase Core Question Answered
Architecture Decision Records (ADR) Macro / System-wide Design & Inception "Why did we choose Kafka over RabbitMQ two years ago?"
OpenAPI / Protobuf / JSON Schema System Boundary (I/O) API Design & Integration "What shape and data types does this endpoint accept?"
Design by Contract (DbC) Code Unit (Class / Function) Runtime Execution "What pre/post conditions must hold inside this method?"
Assumptions & Constraints Manifest (ACM) Change Horizon (PR Diff) Code Review & CI Gate "What silent runtime boundaries is this diff assuming right now?"

Adopt in 4 Steps

Drop-in assets for Cursor, GitHub Copilot, Pull Request templates, and GitHub Actions—now supporting both inline PR blocks and durable .acm.md fallback artifacts in v1.2.

01 / AGENT RULES

Configure IDE Prompts

Add templates/CURSORRULES.md to .cursorrules or .github/copilot-instructions.md to require evidence-backed ACM blocks.

02 / PR TEMPLATE

Embed PR Contract

Copy templates/PULL_REQUEST_TEMPLATE.md into .github/ so agents populate boundaries while humans keep a low-friction path.

03 / CI LINTER

Gate with acm-cli v1.2

Run npx acm-cli validate in GitHub Actions to enforce JSON Schema Draft 2020-12 compliance, proof obligations, and risk floors.

04 / REVIEW GATE

Audit Boundaries First

Reviewers scan Section 2 & 4 in 30 seconds to catch horizontal scaling or data-loss mismatches before reading business logic.

Inline PR Block Single-Pass Synthesis
